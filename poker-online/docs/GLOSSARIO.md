# Glossario (§2)

| Termine | Definizione |
| --- | --- |
| Variante | Regole delle carte: Hold'em (NLHE), Omaha (PLO) |
| Formato | Sessione casual, Sit & Go, allenamento; in seguito MTT |
| Mano | Singola distribuzione, puntate e assegnazione dei piatti |
| Match | Sessione chiusa o torneo con roster iniziale immutabile |
| Roster | Partecipanti assegnati prima dell'avvio |
| Seat | Posizione fisica; non riutilizzabile da un altro partecipante nello stesso match |
| PLAY | Fiches virtuali persistenti del casual, intere |
| Stack torneo | Punti effimeri validi soltanto nel torneo |
| Street contribution | Fiches investite nella street corrente |
| Hand contribution | Fiches investite nell'intera mano |
| RAISE_TO | Totale investito nella street dopo il rilancio (non l'incremento) |
| actedAtLevel | Livello di puntata al momento dell'ultima azione volontaria del seat nella street |
| Proiezione | Vista dello stato autorizzata per un destinatario |
| Versione | Numero monotono dello stato del match |
